# 奧坎剃刀原則、多重共線性 (VIF) 與模型診斷指南

## 1. 奧坎剃刀原則 (Occam's Razor) 在迴歸分析的實踐

> **"Pluralitas non est ponenda sine necessitate"（若無必要，勿增實體）**

在機器學習與統計建模中，特徵絕非越多越好。當加入額外變數時：
- **訓練集表現**：$R^2$ 會單調不減，因為最小平方法（OLS）總能在現有樣本中找到微小的相關性來過度擬合。
- **測試集表現（泛化能力）**：若新特徵實際上只包含雜訊，會導致模型估計的變異數（Variance）急遽膨脹，造成測試集 RMSE 逆勢上升。

### 甜蜜點判定 SOP：
1. 繪製 $k = 1 \dots p$ 的測試集 RMSE 與 $R^2$ 曲線。
2. 找出 RMSE 最低點（即 Sweet Spot）。
3. 檢查增加特徵後的 $p$ 值：若新增特徵的 $p > 0.05$，且 RMSE 未能顯著降低，應依簡約原則剔除該特徵。

## 2. 變異數膨脹因子 (Variance Inflation Factor, VIF)

VIF 用於衡量某預測變數 $X_j$ 與其餘所有自變數之間的多重共線性嚴重程度：

$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$

其中 $R_j^2$ 為以 $X_j$ 為應變數，對其他所有自變數進行輔助迴歸（Auxiliary Regression）所得之決定係數。

### 診斷閾值：
- $\text{VIF} = 1$：完全正交，無共線性。
- $1 < \text{VIF} < 5$：輕度至中度共線性，處於安全且統計上可接受之範圍。
- $5 \le \text{VIF} < 10$：高度共線性，需警惕標準誤膨脹。
- $\text{VIF} \ge 10$：嚴重共線性危機，迴歸係數符號可能顛倒、標準誤急遽擴大，必須進行變數剔除或改用 Ridge/Lasso 正則化。

## 3. APA 標準迴歸報告格式

學術論文與專業報告中，最優模型的輸出應包含以下欄位：
1. **未標準化係數 ($\beta$)**
2. **標準誤 (Std. Error)**
3. **$t$ 統計量 ($t$-statistic)**
4. **顯著性 $p$ 值 ($p$-value)**
5. **95% 信賴區間 (95% CI)**
6. **變異數膨脹因子 (VIF)**
